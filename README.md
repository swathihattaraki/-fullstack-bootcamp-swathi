\## HTTP Methods



| Method | Purpose |

|---|---|

| GET | Retrieve data |

| POST | Create new data |

| PUT | Replace existing data |

| PATCH | Partially update data |

| DELETE | Delete data |



\## Client-Server Request Lifecycle



1\. The user enters employee information in a browser form.

2\. The frontend sends an HTTP request to the backend API.

3\. The backend receives and validates the request.

4\. The backend communicates with the database.

5\. The database processes the operation.

6\. The backend sends an HTTP response.

7\. The browser displays the result.
